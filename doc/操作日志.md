### 2026-10-26 三次加固：保持 JSON 日志合法性与转义键名命中

- `_SECRET_PATTERN` unquoted value 排除 `"`、`\`；`_AUTH_PATTERN` / `_COOKIE_PATTERN` 的 value 同样排除结尾引号与反斜杠，避免吞掉序列化 JSON 的 `",` / `"}`。
- `_SECRET_PATTERN` 键名两侧改为 `(?:\\?["'])?`，可命中 JSON 字符串内的 `\"password\"`。

- **已知限制（日志展示层脱敏，不保证覆盖任意格式）**：含反斜杠的明文如 `password=C:\secret` 只会遮到 `C:`，结果为 `password=***\secret`（value 在 `\` 处截断，剩余部分残留）。脱敏仅保证常见键值/JSON/Header/URL 形态，不能替代结构化日志字段级脱敏。
