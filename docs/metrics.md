# 指标口径

唯一来源：`metrics/metrics.yml`。

| 指标 | 公式 | 归因时间 | 说明 |
|---|---|---|---|
| 成交金额 | SUM(pay_amount) | 支付时间 | 不含未支付/已关闭 |
| 成交单量 | COUNT(*) | 支付时间 | 按订单去重 |
| 客单价 | gmv / order_count | 支付时间 | order_count 为 0 时返回 NULL |

## 原则

- GMV 按支付时间归属，退款按退款完成时间归属，两个口径不混算。
- 无法归属到达人或场次的订单进 `unattributed` 桶，不强行分摊。
- 不定义依赖流量数据的 GPM；分钟级只承诺成交/退款/单量/消耗。
